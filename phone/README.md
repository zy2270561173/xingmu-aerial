# 星投屏手机遥控器

原生 Kotlin + Jetpack Compose Android 应用，最低 Android 6.0（API 23）。电视接收端仍兼容 Android 4.1（API 16）。

已实现：

- 后端地址默认隐藏，登录页或“关于”页连续点击开发者 10 次后才显示；账号登录令牌使用 Android Keystore 加密保存；
- 多设备选择与主控电视切换；
- SSDP 局域网发现；媒体地址优先使用 DLNA 直连，播放控制统一经过电视 Agent；
- 方向键、主页、返回、音量、媒体键、数字键和解码内核切换；
- 主控电视每 0.35 秒尝试请求一帧、最高 1600×900、JPEG 80 的清晰页面预览，只在手机 App 前台请求；画面可点开全屏并使用预设遥控键；
- HTTP/HTTPS、M3U8 地址投屏；
- 手机本地视频的 HTTP Range 局域网直传；
- 单张图片和最多 200 张图片循环幻灯片；
- “终止投屏并退出播放器”会同时取消电视幻灯片定时器和手机本地媒体服务；
- APK 上传、SHA-256 校验与电视系统安装器唤起；
- 命令的排队、送达、执行中、完成和失败状态。
- 独立“Agent”页可查看主控电视全部上报信息、打开电视无障碍/开发者设置、唤醒电视前台或确认删除旧设备；多选继续使用复选框。
- 设备列表和遥控页显示电视系统版本、当前应用、可用内存以及无障碍/Root 的实际遥控与采集级别。
- 手机 App 直接连接和管理后端，不依赖 Web 页面；普通用户可审批绑定给自己的电视，超级管理员可管理全部电视。
- 独立“应用”页显示主控电视的真实图标、应用名称、包名、版本、系统/用户类型和启动状态，并可直接下发打开指令。
- “Agent”页包含独立的关于区域，显示开发者慕沄、为家里老人远程协助电视及避免投屏广告打断的开发初衷、版本和状态检测。
- App 和 Web 均可在电视已授权 ADB 或 Root 时确认执行远程关机；无这些系统能力时按钮会保持不可用。
- 登录后每 6 小时自动检查手机端新版本，也可手动检查；APK 下载后校验哈希、包名和版本码，再交给系统安装器确认安装。

本地媒体服务只接受所选电视上报的局域网 IP，不接受其他设备访问。登录令牌只通过 HTTPS 请求头或 WebSocket 首帧发送，不进入 URL。

画面解码、WebSocket 重连和本地媒体连接均做了并发限制，避免慢电视或断流连接在手机端堆积任务。页面预览用于遥控反馈，不等同于 30fps 屏幕镜像。

构建：

```powershell
$env:JAVA_HOME='D:\Android\Android Studio\jbr'
.\gradlew.bat testDebugUnitTest lintDebug assembleDebug
```

若工程所在路径包含中文且本机 Java 测试进程报 `ClassNotFoundException`，可从指向工程的纯英文目录联接执行测试；源码与产物不需要移动。

可直接安装的测试包位于 `releases/StarlightTvCast-Mobile-0.7.0-debug.apk`。
