## 二、已验证可用

### 电视端（`app.xingmu.aerial`）

- 安装、启动、设备注册、心跳、在线状态上报；
- 控制中心（模态卡片式右侧面板），焦点导航可遍历全部选项，无滚动依赖；
- 页面结构：
  - 投屏设置：状态 / 停止投屏 / 连接设置 / 账号与会员 / 关于本机
  - 连接设置：无障碍、ADB 端口、后端地址、设备名、重新绑定
  - 关于本机：设备名、型号、系统、局域网 IP、版本、投屏状态 + 署名
  - 账号与会员：账号、会员、套餐（可点选）、刷新
  - 购买会员：套餐、金额、状态、收款二维码、刷新支付状态
- 设备认证接口：`/api/vip/device/status`、`/api/vip/device/plans`、`/api/vip/device/payments`；
- 扫码绑定：未绑定设备显示绑定码 + ZXing 二维码；
- 绑定后自动刷新：WS 收到 `binding_updated` 或重连 `authenticated` 都会重新拉账号并重绘；
- 播放：ijkplayer 硬解 + 后端中继（4.4 实机出画面）；
- DLNA 接收（端口 8766）、应用清单上报、截图（`snapshot`）。

### 手机端（`app.xingmu.remote`）

- 设备列表、遥控（方向/OK/主页/返回/音量）、投屏、应用、我的；
- P2P 直连：与电视完成 rendezvous 配对，双方 `established`，界面显示"P2P 直连 · 已连接"；
- 实时画面与遥控可用（该 4.4 机器实际走 ADB TCP，见限制）。

### 后端

- 设备注册/审批/心跳/命令通道；
- VIP：套餐、订单、易支付下单与查单、会员发放；
- 绑定：`POST /api/pairing/{code}/claim` **扫码即通过**（自动 approved + 推送 `binding_updated`）；
- P2P：UDP rendezvous，双方 hello 后下发对端地址。

## 三、已知限制（不是 bug，是环境能力）

1. **4.4 无法由 App 注入按键**：`input keyevent` 需要 INJECT_EVENTS 权限。解决方式：由后端经 adb 注入（已验证）。
2. **4.4 的 `screencap -p` 输出 JPEG**（不是 PNG），脚本处理时需注意。
3. **4.4 没有 MediaProjection**，所以"UDP 传视频"在该机不可用；P2P 承载信令与控制，画面走 ADB TCP 抓屏。
4. **4.4 设置默认桌面**：`pm set-home-activity` 不支持，需在系统弹出的选择框里选"始终"。
5. **4.4 触摸坐标缩放**：`wm size` 报 1920×1080，但 `input tap` 实际按约 0.9 倍生效，自动化时需换算。
